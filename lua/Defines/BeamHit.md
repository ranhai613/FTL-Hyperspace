# Enum "BeamHit"

| Name | Value | Description |
| --- | --- | --- |
| SAME_TILE | 0 | Treat beam hit as same tile as last frame |
| NEW_TILE | 1 | Treat beam hit as new tile but same room as last frame |
| NEW_ROOM | 2 | Treat beam hit as new room from last frame |
